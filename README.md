# To-Eat-List

一个帮助我在校园外卖场景下决定每天吃什么的个人饮食管理项目。

## 项目背景
我平时主要吃学校周边外卖，店铺很多、价格不同、口味差异也大，常常会纠结今天吃什么。
同时，我很喜欢喝奶茶，希望不是强行戒掉，而是在真实生活里做一个更合理的平衡。

## 项目目标
To-Eat-List 希望帮助我根据每天的实际情况，给出更合理的饮食建议，包括：

- 根据预算选择合适的外卖
- 根据口味偏好筛选更想吃的食物
- 记录学校周边新发现的外卖
- 考虑奶茶摄入情况，避免高糖高油失控
- 根据“今天突然想吃什么”动态调整推荐结果
- 生成当天饮食总结，并支持邮件发送

## 目标用户
当前主要面向我自己，后续可以扩展到其他有类似需求的学生用户。

## 核心输入
- 今日预算
- 今日口味偏好
- 今天突然想吃的东西
- 今日是否已经喝了奶茶
- 新发现的外卖信息
- 个人长期饮食偏好

## 核心输出
- 今日推荐吃什么
- 备选外卖
- 预算说明
- 营养提醒
- 奶茶提醒
- 每日总结邮件

## 核心功能
- 外卖信息录入与管理
- 用户饮食偏好记录
- 今日需求输入
- 饮食推荐计算
- 奶茶摄入控制提醒
- 每日饮食总结生成
- 邮件发送功能
