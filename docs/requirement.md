# To-Eat-List 需求说明

## 1. 项目背景
平时主要依赖学校周边外卖解决吃饭问题，但选择太多，经常纠结。
同时，不同外卖价格差异较大，营养情况也不一样。
另外，喜欢喝奶茶，希望能在不完全戒掉的情况下，对饮食做更合理的平衡。

## 2. 主要问题
当前主要存在以下问题：

- 每天不知道吃什么
- 学校周边外卖很多，但难以快速筛选
- 外卖价格不统一，预算容易超支
- 饮食容易偏油、偏甜、不够均衡
- 奶茶喝得比较多，想适当控制
- 有时会突然特别想吃某种东西，希望系统能灵活调整推荐结果

## 3. 项目目标
做一个个人饮食决策助手，帮助我根据以下因素决定每天吃什么：

- 预算
- 口味偏好
- 营养情况
- 奶茶摄入
- 学校周边外卖信息
- 当天突然想吃的内容
- 新发现的外卖

## 4. 核心输入
用户每天可能输入的信息包括：

- 今日预算
- 今日想吃的口味
- 今天突然想吃的东西
- 今天是否已经喝过奶茶
- 今日特殊状态（如心情、疲惫、想放纵一下）
- 新发现的外卖信息

用户长期信息包括：

- 饮食偏好
- 不喜欢吃的食物
- 辣度接受程度
- 奶茶习惯
- 健康目标（减脂 / 维持 / 放松）

## 5. 核心输出
系统需要输出以下内容：

- 今日最推荐的外卖
- 若干备选项
- 价格说明
- 简单营养评价
- 奶茶提醒
- 是否建议下一餐调整
- 每日总结邮件

## 6. 第一版 MVP 范围
第一版只做最小可用版本，优先完成：

- 外卖数据录入
- 用户今日需求输入
- 基于简单规则进行推荐
- 简单奶茶提醒
- 简单营养提示
- 每日总结生成

第一版暂不优先考虑：

- 自动抓取外卖平台数据
- 精确热量计算
- 很复杂的 AI 对话能力
- 复杂的可视化分析
